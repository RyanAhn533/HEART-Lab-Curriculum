## 왜 배우는가

Chapter 2에서 로지스틱 회귀로 분류를 배웠다. 로지스틱은 **직선 하나**로 나눈다.
결정트리는 **질문을 연속으로 던져서** 나눈다 — 사람의 사고방식과 가장 비슷하다.

---

## 1. 결정트리란?

**"예/아니오 질문을 반복해서 정답에 도달하는 구조"**

```
                [나이 ≥ 30?]
               /            \
            Yes              No
        [소득 ≥ 5000?]     [학생?]
         /        \        /     \
       Yes        No     Yes     No
      대출O      대출X   대출O   대출X
```

- 각 노드 = 하나의 질문 (특성 + 기준값)
- 리프 노드 = 최종 답 (분류 결과)
- 해석하기 쉬움 — "왜 이렇게 분류했는지" 설명 가능

---

## 2. 어떤 질문을 먼저 할까? — 정보이득 (Information Gain)

트리를 만들 때 핵심: **"어떤 특성으로 먼저 나눌까?"**

→ **가장 잘 나눠지는 특성**을 먼저 선택 = 정보이득이 가장 큰 특성

### 엔트로피 (Entropy)

```
"데이터가 얼마나 섞여있는가" (불순도)

전부 고양이 → 엔트로피 = 0 (깔끔)
반반 섞임   → 엔트로피 = 1 (최대 혼란)
```

### 정보이득

```
정보이득 = 부모 엔트로피 - 자식 가중 엔트로피

높을수록 → 그 특성으로 나누면 잘 나뉜다 → 먼저 선택
```

---

## 3. 과적합 문제

트리를 너무 깊게 만들면 → **훈련 데이터를 외워버림** (과적합)

### 방지 방법

| 방법 | 설명 |
|------|------|
| max_depth | 트리 최대 깊이 제한 |
| min_samples_split | 분할 최소 샘플 수 |
| min_samples_leaf | 리프 최소 샘플 수 |
| 가지치기 (Pruning) | 불필요한 가지 제거 |

---

## 4. 결정트리의 장단점

| 장점 | 단점 |
|------|------|
| 해석 쉬움 (시각화 가능) | 과적합에 취약 |
| 스케일링 불필요 | 데이터 변화에 민감 (불안정) |
| 범주형/연속형 모두 가능 | 단일 트리는 성능 한계 |

→ 단점 해결 = **3-2 랜덤포레스트 (트리 여러 개)**
