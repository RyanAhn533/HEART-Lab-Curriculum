# 3-6. 정답 없이 그룹 찾기 — K-Means (비지도학습)

> **Ref: Coursera C3W1 Lab / Stanford CS229 W6 / 정규과정 W11**

---

## 왜 배우는가

지금까지는 **지도학습**: 정답(y)이 있고, 그걸 맞추는 모델을 만들었다.
하지만 현실에는 **정답이 없는 데이터**도 많다:
- 고객을 유형별로 나누고 싶은데 → 유형의 정의가 없다
- 비슷한 이미지끼리 묶고 싶은데 → 라벨이 없다

이때 **비지도학습**을 쓴다. K-Means는 가장 기본적인 군집화 알고리즘.

---

## 1. K-Means 알고리즘

```
1. K개의 중심점(centroid)을 랜덤 배치
2. 각 데이터를 가장 가까운 중심점에 할당
3. 각 그룹의 평균으로 중심점 업데이트
4. 2~3 반복 → 중심점이 안 움직이면 종료
```

---

## 2. K 선택 — Elbow Method

K를 몇으로 해야 하는가? → **관성(Inertia)**이 급격히 꺾이는 지점.

```
K=1: ████████████ (높음)
K=2: ██████       (많이 줄음)
K=3: ████         (줄음)
K=4: ███          (조금 줄음) ← Elbow
K=5: ██           (거의 안 줄음)

→ K=3~4가 적당
```

---

## 3. K-Means의 한계

- K를 미리 정해야 함
- 원형(구형) 군집만 잘 찾음 (초승달 모양 등은 못 찾음)
- 초기 중심점에 따라 결과가 달라짐 (n_init으로 여러 번 시도)
