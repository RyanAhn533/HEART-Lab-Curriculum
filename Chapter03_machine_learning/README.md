## 이 Chapter의 목표

Chapter 2에서 선형회귀와 로지스틱 회귀를 배웠다.
이 두 모델은 **선형(직선)**으로 데이터를 나눈다.

현실 데이터는 직선으로 안 나뉘는 경우가 많다.
이 Chapter에서 **비선형 모델들**을 배우고, 같은 데이터에 여러 모델을 적용해서 비교한다.

마지막에 **"전통 ML의 한계"**를 직접 확인하고, Chapter 4 딥러닝으로 넘어간다.
