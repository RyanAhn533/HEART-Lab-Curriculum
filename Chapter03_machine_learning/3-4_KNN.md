# 3-4. 가까운 이웃을 보면 — KNN (K-Nearest Neighbors)

> **가장 직관적인 분류 알고리즘. "나와 가장 비슷한 K개를 보고 다수결"**

---

## 왜 배우는가

KNN은 **학습이 없다**. 모델을 만들지 않고, 예측할 때 **데이터를 직접 비교**한다.
가장 단순하지만 의외로 잘 작동하는 경우가 많다.

---

## 1. KNN이란?

```
새 데이터 ★가 들어오면:
1. 기존 데이터와의 거리를 전부 계산
2. 가장 가까운 K개를 찾음
3. 그 K개의 다수결로 분류

K=3이면:
  가장 가까운 3개가 [고양이, 고양이, 강아지]
  → 다수결 = 고양이
```

---

## 2. K 선택

| K | 특징 |
|---|------|
| K=1 | 가장 가까운 1개 → 노이즈에 민감 (과적합) |
| K=3~7 | 적당한 선택 |
| K=큰 수 | 너무 많이 보면 경계가 뭉개짐 (과소적합) |

→ 보통 **홀수**로 선택 (동점 방지)

단, "홀수로 동점 방지"는 **이진분류에서만** 성립 — 다중분류(Iris 3클래스)에선 K=3이 1:1:1로 여전히 동점이 날 수 있고, sklearn은 이때 거리순(더 가까운 이웃 우선)으로 해소한다.

최적 K도 max_depth처럼 **test로 고르면 안 된다** (2-8 원칙) — train을 다시 train/val로 나눠 val로 고른다.

---

## 3. 거리 측정

| 거리 | 수식 | 특징 |
|------|------|------|
| 유클리드 | √(Σ(a-b)²) | 가장 일반적 |
| 맨해튼 | Σ|a-b| | 격자 이동 |
| 민코프스키 | 일반화 | 유클리드/맨해튼 포함 |

**스케일링 필수!** — 범위가 다르면 거리가 왜곡된다.

---

## 4. KNN의 장단점

| 장점 | 단점 |
|------|------|
| 구현 쉬움, 직관적 | 데이터 많으면 느림 (전부 비교) |
| 학습 불필요 | 고차원에서 성능 하락 |
| 비선형 경계 가능 | K, 거리 선택에 민감 |
