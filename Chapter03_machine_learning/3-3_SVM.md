# 3-3. 가장 넓은 경계로 나누기 — SVM (Support Vector Machine)

> **Ref: Stanford CS229 W3 / 정규과정 4/29~5/1 SVM 슬라이드**

---

## 왜 배우는가

로지스틱 회귀: 나누는 선 하나 → **"어떤 선이든 나누면 됨"**
SVM: 나누는 선 하나 → **"가장 여유 있게 나누는 선을 찾자"**

이 "여유" = **마진(Margin)**. 마진이 클수록 새 데이터에 대해 안정적.

---

## 1. SVM의 핵심 아이디어

**"두 그룹 사이에 가장 넓은 도로를 깔자"**

```
    ○ ○ ○ ○         ● ● ● ●
    ○ ○ ○     | 마진 |     ● ● ●
    ○ ○ ○ ○   |←───→|   ● ● ● ●
              결정경계
```

- **서포트 벡터**: 경계에 가장 가까운 데이터 점들 (도로 가장자리에 있는 점)
- **마진**: 서포트 벡터에서 결정경계까지의 거리 × 2
- **목표**: 마진을 최대화하는 경계를 찾는 것

---

## 2. 커널 트릭 (Kernel Trick) — 직관만

직선으로 안 나뉘는 데이터가 있다:

```
    ● ○ ● ○ ●     → 1D에서는 안 나뉨
    
    ●       ●
      ○ ○ ○        → 2D로 변환하면 원으로 나뉨!
    ●       ●
```

**커널**: 데이터를 더 높은 차원으로 보내서 선형으로 나눌 수 있게 만드는 함수.

| 커널 | 용도 |
|------|------|
| linear | 이미 선형으로 나뉘는 경우 |
| rbf (기본값) | 대부분의 경우 잘 작동 |
| poly | 다항식 경계가 필요할 때 |

---

## 3. 소프트 마진 (Soft Margin)

현실 데이터는 완벽하게 안 나뉨 → 약간의 오분류를 허용.

**C 파라미터**: 오분류 허용 정도
- C 큼 → 오분류 적게 (과적합 위험)
- C 작음 → 오분류 많이 허용 (과소적합 위험)

---

## 4. SVM의 장단점

| 장점 | 단점 |
|------|------|
| 고차원 데이터에 강함 | 대규모 데이터에 느림 |
| 마진 최대화 → 일반화 좋음 | 확률 출력 어려움 |
| 커널로 비선형 처리 가능 | 하이퍼파라미터 튜닝 필요 |
