# 3-2. 트리를 여러 개 합치면 — 랜덤포레스트 (Random Forest)

> **Ref: Coursera C2W4 Lab02 / AI5 ml/m37 Bagging**

---

## 왜 배우는가

3-1에서 결정트리의 단점을 봤다: **과적합, 불안정**.
트리 1개가 불안정하면 → **트리 100개를 만들어서 투표**시키면 안정적이 된다.
이게 **앙상블(Ensemble)**의 핵심 아이디어.

---

## 1. 앙상블이란?

**"여러 모델의 결과를 합쳐서 더 좋은 결과를 만드는 것"**

```
트리 1: 고양이  ─┐
트리 2: 강아지   ├→ 투표 → 고양이 (2:1)
트리 3: 고양이  ─┘
```

---

## 2. Bagging (Bootstrap Aggregating)

1. 원본 데이터에서 **랜덤 복원 추출**로 여러 부분집합 생성
2. 각 부분집합으로 **독립적인 트리** 학습
3. 예측할 때 **전체 트리의 투표(분류) 또는 평균(회귀)**

---

## 3. 랜덤포레스트 = Bagging + 특성 랜덤 선택

Bagging에 한 가지 더 추가: 각 분할에서 **특성도 랜덤으로 일부만** 사용.
→ 트리들이 더 다양해짐 → 앙상블 효과 극대화

```
일반 Bagging:  데이터만 랜덤
랜덤포레스트:  데이터 + 특성 둘 다 랜덤
```

---

## 4. 핵심 하이퍼파라미터

| 파라미터 | 의미 | 기본값 |
|---------|------|--------|
| n_estimators | 트리 개수 | 100 |
| max_depth | 각 트리 최대 깊이 | None (제한 없음) |
| min_samples_split | 분할 최소 샘플 | 2 |
| max_features | 각 분할에서 사용할 특성 비율 | 'sqrt' |

---

## 5. XGBoost (Gradient Boosting)

랜덤포레스트와 다른 앙상블 방식:
- RF: 트리를 **독립적으로** 만들고 투표
- XGBoost: 이전 트리의 **실수를 다음 트리가 보완**

→ 실무에서 **테이블 데이터 최강** 모델. Kaggle 대회 우승 단골.
