---

## 1. 경사하강법이란?

**"산에서 가장 빠르게 내려가는 법"**

1. 현재 위치에서 **기울기(gradient)**를 구한다 — "어느 방향이 아래인가?"
2. 그 방향으로 **한 발짝** 이동한다
3. 반복한다 → 최저점(손실 최소)에 도달

```
w_new = w_old - lr × gradient

w_new:    업데이트된 가중치
w_old:    현재 가중치
lr:       학습률 (learning rate) — 한 발짝의 크기
gradient: 기울기 — 현재 위치에서 손실이 증가하는 방향
```

---

## 2. Learning Rate (학습률)

한 발짝의 크기. **lr이 학습을 결정한다.**

| lr | 현상 |
|----|------|
| 너무 큼 (0.1~1.0) | 최저점을 지나쳐서 왔다갔다 (발산) |
| 적당함 (0.001~0.01) | 안정적으로 수렴 |
| 너무 작음 (0.000001) | 너무 느리게 내려감 (수렴 안 함) |

---

## 3. Gradient (기울기)

**"현재 위치에서 손실 곡선의 기울기"**

- 기울기 > 0 → w를 줄여야 함 (오른쪽이 높으니까)
- 기울기 < 0 → w를 늘려야 함 (왼쪽이 높으니까)
- 기울기 = 0 → 최저점 (학습 완료)

```
MSE의 gradient (w에 대해):
gradient = -(2/n) × Σ x × (y - (wx + b))
```

---

## 4. 학습 과정

```
Epoch 1:   w=0.0, MSE=20.0   (완전 틀림)
Epoch 10:  w=1.2, MSE=5.3    (나아지는 중)
Epoch 50:  w=1.8, MSE=0.5    (거의 수렴)
Epoch 100: w=2.0, MSE=0.01   (최적에 도달)
```

Epoch = 전체 데이터를 한 번 학습하는 것.

---

## 5. Optimizer 종류 (직관만)

| Optimizer | 설명 |
|-----------|------|
| SGD | 가장 기본, 매 데이터마다 업데이트 |
| Momentum | 관성 추가 (공이 굴러가는 것처럼) |
| RMSprop | 방향별로 lr 자동 조절 |
| **Adam** | Momentum + RMSprop (가장 많이 사용) |

→ 지금은 **Adam만 기억**하면 된다.
