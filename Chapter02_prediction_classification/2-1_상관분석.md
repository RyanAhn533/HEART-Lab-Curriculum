# 2-1. 두 변수의 관계 — 상관분석 (Correlation Analysis)

> **Ref: Stanford CS229 W1 / Google MLCC "Linear Regression"**

---

## 왜 배우는가

모델을 만들기 전에 **"이 특성(X)이 결과(Y)와 관련이 있는가?"** 알아야 한다.
관련 없는 특성을 넣으면 모델이 혼란스러워지고, 성능이 떨어진다.

---

## 1. 상관계수 (Correlation Coefficient)

두 변수가 **얼마나 같이 움직이는가**를 -1 ~ +1로 표현.

| 값 | 의미 |
|----|------|
| +1 | 완벽한 양의 상관 (X↑ → Y↑) |
| 0 | 관계 없음 |
| -1 | 완벽한 음의 상관 (X↑ → Y↓) |

```
|r| > 0.7  → 강한 상관
|r| > 0.4  → 중간 상관
|r| < 0.2  → 거의 없음
```

### 상관 ≠ 인과

```
아이스크림 판매량 ↑ → 익사 사고 ↑
→ 상관관계는 있지만, 인과는 아니다 (원인: 여름/더위)
```

### Pearson vs Spearman

위의 상관계수는 **Pearson** — 두 변수의 **직선 관계** 강도를 잰다.
**Spearman**은 값 대신 **순위(rank)**로 계산한다 — 직선이 아니어도 "단조롭게" 같이 증가/감소하면 잡아내고, 이상치에도 강하다.
코드는 `df.corr(method='spearman')` 한 줄.

### 상관 0 ≠ 관계 없음

Pearson r은 직선 관계만 잰다. y = x² 같은 **완벽한 관계도 r ≈ 0**이 나온다.

```python
x = np.linspace(-3, 3, 100)
y = x ** 2                       # 완벽한 관계 (포물선)
print(np.corrcoef(x, y)[0, 1])   # ≈ 0.0 — 직선이 아니라서 못 잡는다
plt.scatter(x, y)                # 눈으로 보면 관계가 뚜렷!
```

→ 상관계수 숫자만 믿지 말고 **scatter를 꼭 그려봐라**.

---

## 2. 공분산 (Covariance)

상관계수의 **원재료**. 두 변수가 평균에서 같은 방향으로 벗어나는 정도.

- 양수 → 같은 방향으로 움직임
- 음수 → 반대 방향으로 움직임
- 단위가 있어서 크기 비교 어려움 → **상관계수로 정규화**

---

## 3. 시각화

- **scatter plot**: 두 변수의 관계를 점으로
- **heatmap**: 모든 변수 쌍의 상관계수를 색으로
- **추세선 (regression line)**: scatter에 직선 추가 → 2-2 선형회귀로 연결
