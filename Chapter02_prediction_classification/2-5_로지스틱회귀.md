# 1-10. 분류의 시작 — 로지스틱 회귀 (Logistic Regression)

> **Ref: Stanford CS229 W2 / Coursera C1W3 / Google MLCC "Logistic Regression"**

---

## 왜 배우는가

1-7에서 선형회귀로 **숫자를 예측**했다. 이제 **"어느 쪽인가?"**를 판단하는 문제.

- 이 메일은 스팸인가 아닌가?
- 이 종양은 악성인가 양성인가?
- 이 고객은 이탈할 것인가 아닌가?

이런 문제가 **이진분류 (Binary Classification)**.

---

## 1. 왜 선형회귀로 분류가 안 되는가?

선형회귀 출력: -∞ ~ +∞ (어떤 숫자든 가능)
분류에 필요한 출력: 0 ~ 1 (확률)

→ 출력을 **0~1 사이로 압축**하는 함수가 필요 = **Sigmoid**

---

## 2. Sigmoid 함수

```
σ(z) = 1 / (1 + e^(-z))
```

- 입력이 뭐든 출력은 **0~1**
- z가 매우 크면 → 1에 가까움
- z가 매우 작으면 → 0에 가까움
- z = 0이면 → 0.5 (반반)

```
로지스틱 회귀 = 선형회귀 + Sigmoid

z = wx + b          ← 선형회귀 (1-7에서 배운 것)
y = sigmoid(z)      ← 0~1로 압축
```

---

## 3. 결정 경계 (Decision Boundary)

**"확률 0.5를 기준으로 나눈다"**

```
sigmoid(wx + b) ≥ 0.5 → 양성 (1)
sigmoid(wx + b) < 0.5 → 음성 (0)
```

이 기준선이 **결정 경계**. 시각적으로는 데이터를 가르는 직선.

---

## 4. 다중분류 (Softmax)

클래스가 3개 이상일 때 → **Softmax**

```
Softmax = 각 클래스의 확률을 구하되, 전체 합 = 1

입력: [2.0, 1.0, 0.1]
Softmax: [0.66, 0.24, 0.10]  (합 = 1.0)
→ 클래스 0일 확률 66%
```

---

## 5. 왜 이름이 "회귀"인데 분류인가?

로지스틱 회귀는 **확률을 회귀**하는 것.
0~1 사이의 확률값을 예측하고, 그 확률로 분류를 결정.

---

## 나중에 만나는 곳

| 여기서 배운 것 | 나중에 만나는 곳 | 어떻게 쓰이는가 |
|--------------|---------------|---------------|
| Sigmoid | Phase 5~6 | `activation='sigmoid'` (이진분류) |
| Softmax | Phase 5~6 | `activation='softmax'` (다중분류) |
| 결정경계 | Phase 3 SVM | 마진 최대화 경계 |
