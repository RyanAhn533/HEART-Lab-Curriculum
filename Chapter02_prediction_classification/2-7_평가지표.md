# 2-7. 모델이 잘 했는가 — 평가지표 (Evaluation Metrics)

> **Ref: Google MLCC "Classification: Metrics" / Stanford CS229 W7 / Coursera C2W3**

---

## 왜 배우는가

모델을 만들었다. **"이 모델 괜찮은가?"**를 판단하는 기준이 평가지표.
Accuracy만 보면 큰 실수를 할 수 있다.

---

## 1. 혼동행렬 (Confusion Matrix)

분류 결과를 **표 하나**로 정리.

```
                예측: 양성    예측: 음성
실제: 양성       TP            FN
실제: 음성       FP            TN
```

| 약어 | 의미 | 설명 |
|------|------|------|
| TP | True Positive | 양성을 양성으로 맞춤 |
| FP | False Positive | 음성을 양성으로 틀림 (1종 오류) |
| FN | False Negative | 양성을 음성으로 틀림 (2종 오류) |
| TN | True Negative | 음성을 음성으로 맞춤 |

---

## 2. Accuracy (정확도)

```
Accuracy = (TP + TN) / (TP + FP + FN + TN)
= "전체 중 맞춘 비율"
```

### Accuracy의 함정

```
1000명 중 암 환자 10명, 정상 990명
모델이 전부 "정상"이라고 예측 → Accuracy = 99%
→ 하지만 암 환자 10명을 전부 놓침!
```

**불균형 데이터에서 Accuracy는 위험하다.**

---

## 3. Precision (정밀도)

```
Precision = TP / (TP + FP)
= "양성이라고 한 것 중 진짜 양성 비율"
```

- **FP를 줄이고 싶을 때** 중요
- 예: 스팸 필터 — 정상 메일을 스팸으로 분류하면 안 됨

---

## 4. Recall (재현율 / 민감도)

```
Recall = TP / (TP + FN)
= "진짜 양성 중 찾아낸 비율"
```

- **FN을 줄이고 싶을 때** 중요
- 예: 암 진단 — 암 환자를 놓치면 안 됨

### 주의 — sklearn breast_cancer의 라벨 방향

실습에서 쓰는 breast_cancer 데이터는 **target 1 = benign(양성종양), 0 = malignant(악성)**이다.
sklearn의 precision/recall은 기본적으로 **1(양성종양)을 positive로** 계산한다.
"암(악성)을 놓치지 않기 = Recall" 서사로 읽으려면 **악성(0)을 positive로 뒤집어야** 한다:
`recall_score(y_test, y_pred, pos_label=0)` — 실습 py에서 둘 다 계산해 비교한다.

---

## 5. F1 Score

```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
= Precision과 Recall의 조화 평균
```

- 둘 다 중요할 때 **하나의 숫자로** 평가
- 불균형 데이터에서 Accuracy 대신 사용

---

## 6. ROC / AUC

**ROC 곡선**: threshold(0.5 기준)를 바꿔가며 TPR(Recall) vs FPR을 그린 곡선.
**AUC**: ROC 곡선 아래 면적 (1에 가까울수록 좋음).

| AUC | 의미 |
|-----|------|
| 1.0 | 완벽 |
| 0.9+ | 매우 좋음 |
| 0.7~0.9 | 괜찮음 |
| 0.5 | 랜덤 (쓸모없음) |

---

## 7. 정리: 언제 뭘 보나?

| 상황 | 보는 지표 |
|------|---------|
| 균형 데이터 | Accuracy |
| 불균형 데이터 | F1, Precision, Recall |
| FP가 치명적 (스팸 필터) | Precision |
| FN이 치명적 (암 진단) | Recall |
| 전체적인 분류 성능 | AUC |
| 논문 결과표 | Accuracy + F1 + AUC |

### classification_report의 macro / weighted avg

- **macro avg**: 클래스별 지표의 단순 평균 — 소수 클래스도 동등하게 취급
- **weighted avg**: 클래스별 지표를 샘플 수로 가중 평균 — 다수 클래스에 끌려감

### 불균형 자체를 다루는 방법도 있다

지표로 감시하는 것 외에 **불균형 자체를 처리**하는 방법: `class_weight='balanced'`, 오버/언더샘플링(리샘플링) — Chapter 9에서 다룬다.
