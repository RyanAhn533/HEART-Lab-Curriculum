# 1-7. 직선으로 예측하기 — 선형회귀 (Linear Regression)

> **Ref: Stanford CS229 W2 / Coursera C1W1~W2 / Google MLCC "Linear Regression"**

---

## 왜 배우는가

**"과거 데이터를 보고 미래를 예측한다"** — 이게 머신러닝의 시작이다.

가장 간단한 예측 방법 = **직선 하나 긋기**.
이 직선이 바로 선형회귀 모델이다.

---

## 1. 선형회귀란?

데이터에 **가장 잘 맞는 직선**을 찾는 것.

```
y = wx + b

y: 예측하고 싶은 값 (타겟)
x: 예측에 사용하는 값 (특성)
w: 기울기 (weight) — x가 1 증가하면 y가 w만큼 변함
b: 절편 (bias) — x가 0일 때 y값
```

### 예시
```
면적(x)    집값(y)
20평       2억
30평       3억
40평       4억

→ y = 0.1x + 0   (기울기 0.1, 절편 0)
→ 50평 집값 예측 = 0.1 × 50 = 5억
```

---

## 2. 최소자승법 (OLS: Ordinary Least Squares)

"가장 잘 맞는 직선" = **모든 점에서 직선까지 거리(오차)의 제곱합이 최소인 직선**

```
오차 = 실제값 - 예측값
오차² = (실제값 - 예측값)²
OLS = 모든 오차²의 합을 최소화하는 w, b를 찾는다
```

### 잔차 (Residual)
각 데이터 점에서 직선까지의 수직 거리.
잔차가 작을수록 좋은 모델.

---

## 3. R² (결정계수)

**"이 모델이 데이터를 얼마나 잘 설명하는가"**

| R² 값 | 의미 |
|--------|------|
| 1.0 | 완벽하게 설명 (모든 점이 직선 위) |
| 0.7~0.9 | 좋은 모델 |
| 0.4~0.7 | 보통 |
| < 0.4 | 선형으로는 부족 |
| < 0 | 평균보다 못 함 |

---

## 4. 다중 선형회귀

입력이 **여러 개**일 때.

```
y = w₁x₁ + w₂x₂ + w₃x₃ + ... + b

집값 = 0.5×면적 + 0.3×층수 + 0.2×역거리 + 상수
```

현실 문제는 대부분 다중 선형회귀. 특성이 1개인 경우는 거의 없다.

---

## 5. 선형회귀의 한계

- **비선형 관계**는 직선으로 표현 못 함
- 이상치에 민감
- 특성 간 다중공선성 문제

→ 이 한계를 극복하기 위해 **신경망(Phase 5)** 으로 확장

---

## 나중에 만나는 곳

| 여기서 배운 것 | 나중에 만나는 곳 | 어떻게 쓰이는가 |
|--------------|---------------|---------------|
| y = wx + b | Phase 5 신경망 | Dense(1) = 선형회귀와 같은 구조 |
| R² | 모든 회귀 모델 평가 | r2_score() |
| 잔차 | 1-8 손실함수 | MSE = 잔차 제곱의 평균 |
| 다중 회귀 | Phase 5 DNN | 입력 특성 여러 개 |
