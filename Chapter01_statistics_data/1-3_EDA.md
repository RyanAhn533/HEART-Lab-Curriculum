# 1-3. 데이터 탐색 — EDA (Exploratory Data Analysis)

> **Ref: Google MLCC "Working with Numerical/Categorical Data" / Coursera C1W2 특성공학**

---

## 왜 배우는가

EDA = **Exploratory Data Analysis (탐색적 데이터 분석)**

모델에 데이터를 넣기 전에 **"눈으로 먼저 보는 것"**.
데이터를 안 보고 모델을 돌리면, 결과가 이상해도 원인을 찾을 수 없다.

실무에서 ML 엔지니어가 **가장 많은 시간을 쓰는 단계**가 데이터 탐색과 전처리다.
모델 코드는 10줄이지만, 데이터 준비는 100줄이 넘는다.

## 1. 데이터를 처음 만나면 확인할 것

### 순서

```
1) 데이터 크기 확인       → shape
2) 컬럼(특성) 확인        → columns, dtypes
3) 처음/끝 몇 줄 보기     → head(), tail()
4) 기본 통계 확인         → describe()
5) 결측치 확인            → isnull().sum()
6) 데이터 타입 확인       → info()
```

이 6단계를 **자동으로 치는 습관**이 되어야 한다.

---

## 2. 데이터 타입

### 연속형 (Numerical / Continuous)
- 숫자로 측정 가능, 크기 비교 가능
- 예: 키(170.5cm), 온도(36.5도), 가격(15000원)
- 연산 가능: 평균, 표준편차

### 범주형 (Categorical)
- 그룹/카테고리를 나타냄
- 예: 성별(남/여), 혈액형(A/B/O/AB), 학점(A/B/C)
- 연산 불가: 평균 의미 없음

### 왜 구분하나?
- **연속형** → 히스토그램, scatter, 스케일링
- **범주형** → countplot, 인코딩 (숫자로 변환 필요)
- 모델은 **숫자만** 받는다 → 범주형은 반드시 변환해야 함

---

## 3. 시각화로 패턴 찾기

### 분포 확인 (1개 변수)
- **히스토그램 (hist)**: 연속형 변수의 분포
- **countplot**: 범주형 변수의 빈도
- **boxplot**: 이상치와 퍼짐 정도

### 관계 확인 (2개 변수)
- **scatter plot**: 두 연속형 변수의 관계 (상관관계)
- **heatmap**: 모든 변수 간 상관계수를 한눈에
- **pairplot**: 모든 변수 조합의 scatter를 한번에

### 그룹 비교
- **boxplot (그룹별)**: 범주에 따른 연속형 값 비교
- **violinplot**: boxplot + 분포 모양

## 4. describe()가 알려주는 것

```
         count    mean     std     min     25%     50%     75%     max
price   1000.0  35000.0  12000.0  5000.0  28000.0 34000.0 42000.0 95000.0
```

| 항목 | 의미 | 확인 포인트 |
|------|------|-----------|
| count | 데이터 개수 | 결측치 있으면 전체보다 작음 |
| mean | 평균 | 중앙값(50%)과 비교 → 치우침 확인 |
| std | 표준편차 | 클수록 데이터가 많이 퍼짐 |
| min/max | 최소/최대 | 이상하게 크거나 작은 값? |
| 25%/50%/75% | 사분위수 | IQR로 이상치 판별 |

## 5. EDA 체크리스트

```
□ shape 확인 (몇 행, 몇 열?)
□ dtypes 확인 (숫자? 문자? 날짜?)
□ describe() (기본 통계 이상 없는지?)
□ isnull().sum() (결측치 몇 개?)
□ 타겟 변수 분포 (균형? 불균형?)
□ 히스토그램 (각 변수 분포 모양)
□ 상관관계 heatmap (어떤 변수가 관련 있는지)
□ 이상치 확인 (boxplot으로 시각적 확인)
```
