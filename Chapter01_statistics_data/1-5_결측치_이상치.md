# 1-5. 비어있거나 이상한 데이터 — 결측치 / 이상치 처리

> **Ref: Google MLCC "Working with Numerical Data" / Coursera C1W2**

---

## 왜 배우는가

현실 데이터는 완벽하지 않다.
- 센서 오류로 값이 빠져 있거나 (결측치)
- 입력 실수로 비현실적인 값이 있거나 (이상치)

이걸 처리하지 않으면 모델이 엉뚱한 패턴을 학습한다.

---

## 1. 결측치 (Missing Values)

### 결측치란?
데이터가 **비어있는 것**. pandas에서는 `NaN`으로 표시.

### 확인 방법
```python
df.isnull().sum()        # 컬럼별 결측치 개수
df.isnull().sum().sum()  # 전체 결측치 개수
df.info()                # Non-Null Count로 확인
```

### 처리 방법

| 방법 | 코드 | 언제 쓰는가 |
|------|------|-----------|
| 삭제 (행) | `df.dropna()` | 결측치가 소수이고, 데이터가 충분할 때 |
| 삭제 (열) | `df.drop(columns=['col'])` | 해당 열의 결측치가 너무 많을 때 |
| 평균 대체 | `df.fillna(df.mean())` | 연속형, 정규분포에 가까울 때 |
| 중앙값 대체 | `df.fillna(df.median())` | 연속형, 이상치가 있을 때 |
| 최빈값 대체 | `df.fillna(df.mode()[0])` | 범주형 데이터 |
| 보간 | `df.interpolate()` | 시계열 데이터 |

### 왜 빠졌는가 — 결측 메커니즘

같은 결측치라도 **왜 빠졌는지**에 따라 안전한 처리가 달라진다.

| 유형 | 의미 | 예 | 처리 |
|------|------|----|------|
| MCAR | 완전 무작위로 빠짐 | 센서가 랜덤하게 끊김 | 삭제/대체 모두 비교적 안전 |
| MAR | 다른 변수와 관련해 빠짐 | 고령일수록 소득 무응답 | 관련 변수를 활용한 대체 |
| MNAR | 빠진 값 자체 때문에 빠짐 | 소득이 높아서 소득 무응답 | 삭제/단순 대체 모두 왜곡 위험 — 도메인 지식 필요 |

### 주의
- **삭제는 데이터 손실** → 데이터가 적으면 대체가 낫다
- **대체는 왜곡 가능** → 어떤 값으로 대체했는지 기록해야

## 2. 이상치 (Outliers)

### 이상치란?
다른 데이터와 **크게 동떨어진 값**. 측정 오류일 수도, 실제 극단값일 수도 있다.

### 탐지 방법

**IQR 방법 (1-1에서 배운 것)**
```
하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR
→ 범위 밖의 값 = 이상치
```

**Z-score 방법 (1-2에서 배운 것)**
```
Z = (값 - 평균) / 표준편차
|Z| > 3 이면 이상치 (3σ 밖)
```

### 처리 방법

| 방법 | 설명 | 언제 쓰는가 |
|------|------|-----------|
| 제거 | 이상치 행 삭제 | 명백한 오류일 때 |
| 대체 | 상한/하한으로 클리핑 | 극단값을 유지하되 완화 |
| 변환 | 로그 변환 | 분포를 정규화할 때 |
| 유지 | 그대로 둠 | 실제 의미 있는 극단값일 때 |

### 주의
- 이상치가 **항상 나쁜 건 아니다** — 사기 탐지에서는 이상치가 핵심
- **제거 전에 왜 이상치인지** 반드시 확인
