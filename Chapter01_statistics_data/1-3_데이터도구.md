## 1. numpy — 배열(숫자 묶음)을 다루는 도구

### 왜 리스트 대신 numpy?

```python
# 파이썬 리스트: 느리고, 수학 연산 불편
a = [1, 2, 3]
b = [4, 5, 6]
a + b  # → [1, 2, 3, 4, 5, 6]  (이어붙이기, 덧셈 아님!)

# numpy 배열: 빠르고, 수학 연산 자연스러움
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
a + b  # → [5, 7, 9]  (원소별 덧셈!)
```

모든 ML/DL 모델의 입력은 **numpy 배열**이다.

### 핵심 개념: shape

```
shape = 배열의 "크기"

(150,)      → 숫자 150개 (1차원)
(150, 4)    → 150행 × 4열 (2차원) — "150개 데이터, 4개 특성"
(60000, 28, 28) → 6만장 × 28 × 28 (3차원) — "6만장 이미지"

행(row) = 샘플(데이터 1개)
열(col) = 특성(feature, 변수)
```

---

## 2. 행 = 샘플, 열 = 특성

ML에서 데이터는 항상 이 구조:

```
              특성1    특성2    특성3    특성4
샘플1 (환자1)   5.1      3.5      1.4      0.2
샘플2 (환자2)   4.9      3.0      1.4      0.2
샘플3 (환자3)   7.0      3.2      4.7      1.4
...
→ shape: (150, 4) = "150명 환자, 4가지 측정값"
```

| 용어 | 의미 | 예시 |
|------|------|------|
| 샘플 (sample) | 데이터 1개 | 환자 1명, 이미지 1장 |
| 특성 (feature) | 측정값 1개 | 키, 몸무게, 혈압 |
| 타겟 (target) | 정답 | 양성/음성, 가격 |

## 3. 데이터 타입

```python
정수 (int):    1, 2, 3, -5          → 개수, 나이, 클래스 번호
실수 (float):  3.14, 0.001, -2.5    → 키, 온도, 확률
문자 (str):    "남", "여", "서울"    → 범주형 데이터
불린 (bool):   True, False          → 조건 판단
```

모델은 **숫자(int, float)만** 받는다. 문자는 인코딩(1-6)으로 변환해야 한다.

## 4. pandas — 표(DataFrame)로 데이터 다루기

### DataFrame = 엑셀 같은 표

```python
df = pd.DataFrame({
    'name': ['Kim', 'Lee', 'Park'],
    'age':  [25, 30, 28],
    'score': [85, 92, 78],
})
```

```
   name  age  score
0   Kim   25     85
1   Lee   30     92
2  Park   28     78
```

### 자주 쓰는 것

```python
df.shape            # (3, 3) — 3행 3열
df.columns          # ['name', 'age', 'score'] — 컬럼 이름들
df.dtypes           # 각 컬럼의 데이터 타입
df['age']           # age 컬럼만 가져오기
df[df['age'] > 25]  # age가 25 초과인 행만 필터링
df.describe()       # 기술통계 한 번에
```

## 5. matplotlib — 그래프 그리기

### 기본 사용법

```python
plt.plot(x, y)           # 선 그래프
plt.scatter(x, y)        # 점 그래프
```

## 6. 데이터 표현 — 숫자, 범주, 원핫, 벡터

### 숫자형 (Numerical)
```
키: 170.5, 온도: 36.5, 가격: 15000
→ 그대로 모델에 넣을 수 있음
```

### 범주형 (Categorical)
```
성별: 남/여, 혈액형: A/B/O/AB
→ 모델은 문자를 못 읽음 → 숫자로 변환 필요
```

### 라벨 인코딩
```
남 → 0, 여 → 1
A → 0, B → 1, O → 2, AB → 3
→ 간단하지만 "순서"가 생김 (0 < 1 < 2)
```

### 원핫 인코딩 (One-Hot)
```
A → [1, 0, 0, 0]
B → [0, 1, 0, 0]
O → [0, 0, 1, 0]
AB→ [0, 0, 0, 1]
→ 순서 없음, 각 범주가 독립적
```

### 벡터란?
```
데이터 1개 = 숫자들의 묶음 = 벡터 = 공간의 한 점

환자1: [170, 65, 120, 36.5] → 4차원 공간의 한 점
환자2: [165, 55, 110, 36.8] → 4차원 공간의 다른 점

→ "비슷한 환자"는 공간에서 가까이 있다
→ 이게 KNN(3-4)의 원리이고, 임베딩(Chapter 7)의 기초
```
