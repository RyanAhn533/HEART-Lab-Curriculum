# 1-6. 모델이 이해할 수 있는 형태로 — 인코딩 / 스케일링

> **Ref: Google MLCC "Categorical Data" / Coursera C1W2 Feature Scaling**

---

## 왜 배우는가

모델은 **숫자만** 받는다.
- "남성", "여성" → 모델이 이해 못 함 → **인코딩** 필요
- 키(170cm)와 몸무게(70kg) → 범위가 달라서 학습 불균형 → **스케일링** 필요

---

## 1. 인코딩 (Encoding) — 범주형을 숫자로

### Label Encoding
범주에 **번호**를 매김.

```
남성 → 0, 여성 → 1
Sales → 0, Engineering → 1, HR → 2
```

- 간단하지만 **순서가 생김** (0 < 1 < 2)
- 트리 계열 모델에서 주로 사용

### One-Hot Encoding
범주를 **별도 열**로 분리. 해당하면 1, 아니면 0.

```
         Sales  Engineering  HR
김OO       1         0       0
이OO       0         1       0
박OO       0         0       1
```

- 순서 문제 없음
- 신경망, 선형 모델에서 주로 사용
- 범주가 많으면 열이 폭발 (주의)

### 언제 뭘 쓰나?

| 인코딩 | 코드 | 적합한 경우 |
|--------|------|-----------|
| Label | `LabelEncoder()` | 트리 계열, 순서가 있는 범주 (대/중/소) |
| One-Hot | `pd.get_dummies()` | 신경망, 회귀, 순서 없는 범주 |

## 2. 스케일링 (Scaling) — 범위를 맞추기

### 왜 필요한가?

```
키:    155, 160, 170, 180, 185  (범위: 155~185)
연봉:  3000, 4000, 5000, 8000   (범위: 3000~8000)
```

범위가 다르면 모델이 **큰 숫자에 끌려간다**.
스케일링은 모든 특성을 **비슷한 범위**로 맞추는 것.

### MinMaxScaler (0~1 범위로)

```
x_scaled = (x - min) / (max - min)
```

- 결과: 0 ~ 1 사이
- 이상치에 민감 (min/max가 극단값이면 왜곡)

### StandardScaler (평균=0, 표준편차=1로)

```
x_scaled = (x - mean) / std
```

- 결과: 평균 0, 표준편차 1 (정규분포화)
- **1-1에서 배운 평균/표준편차가 여기서 쓰인다**
- 이상치에 상대적으로 강함

### RobustScaler (중앙값과 IQR 기준)

```
x_scaled = (x - median) / IQR
```

- **1-1에서 배운 중앙값/IQR이 여기서 쓰인다**
- 이상치에 가장 강함

### 언제 뭘 쓰나?

| 스케일러 | 이상치 | 적합한 경우 |
|---------|--------|-----------|
| MinMax | 민감 | 이상치 없고, 0~1 범위 필요할 때 |
| Standard | 보통 | 일반적인 경우 (가장 많이 사용) |
| Robust | 강함 | 이상치가 많을 때 |

### 핵심 규칙

먼저, 데이터는 **train/test로 나눈다** (`train_test_split`):
- 모델의 목표는 외운 데이터가 아니라 **새 데이터**를 잘 맞추는 것
- 그래서 일부(test)를 떼어놓고 학습에는 안 쓰고, 마지막 평가에만 쓴다
- 왜 이렇게 하는지의 원리(과적합·일반화)는 **2-8에서 자세히**

```python
# 반드시 train에서 fit, test는 transform만
scaler.fit(X_train)           # train 기준으로 학습
X_train = scaler.transform(X_train)  # train 변환
X_test = scaler.transform(X_test)    # test도 같은 기준으로 변환
```

**왜?** test 데이터의 정보가 학습에 새어나가면 안 된다 (Data Leakage).
