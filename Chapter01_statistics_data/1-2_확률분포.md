# 1-2. 데이터의 모양 — 확률분포 (Probability Distribution)

> **Ref: Stanford CS229 W1 확률이론 / Coursera C1W1 지도/비지도 구분 / Google MLCC "Numerical Data"**

---

## 왜 배우는가

1-1에서 데이터를 **숫자로 요약**했다. 이제 **"데이터가 어떤 모양으로 퍼져 있는가"**를 본다.

데이터의 모양(분포)을 알면:
- 어떤 전처리를 해야 하는지 판단할 수 있다
- 모델이 잘 동작할 조건인지 확인할 수 있다
- 이상한 데이터를 눈으로 발견할 수 있다

---

## 1. 확률분포란?

**"어떤 값이 나올 가능성을 모양으로 표현한 것"**

주사위를 100번 던지면:
- 1~6이 각각 약 16~17번 → **균등분포** (어디든 비슷)

학생 100명의 키를 재면:
- 165~175cm에 몰려있고, 극단은 적음 → **정규분포** (종 모양)

---

## 2. 정규분포 (Normal Distribution / Gaussian)

가장 중요한 분포. **"대부분의 자연 현상이 이 모양"**

### 특징
- 평균을 중심으로 **좌우 대칭** (종 모양)
- 평균 ± 1 표준편차 안에 데이터의 **약 68%**
- 평균 ± 2 표준편차 안에 데이터의 **약 95%**
- 평균 ± 3 표준편차 안에 데이터의 **약 99.7%**

### 68-95-99.7 법칙

```
         99.7%
      ┌─────────────┐
      │    95%       │
      │  ┌───────┐   │
      │  │  68%  │   │
──────┼──┼───┼───┼───┼──────
    -3σ -2σ  -1σ  μ  +1σ +2σ +3σ
```

### 왜 중요한가?

1. **StandardScaler**가 데이터를 평균=0, 표준편차=1인 정규분포로 변환
2. 많은 ML 알고리즘이 **정규분포에 가까운 데이터**에서 더 잘 작동
3. **이상치 판별**: 3σ 밖의 데이터 = 이상치 (Z-score 방법)

---

## 3. 이항분포 (Binomial Distribution)

**"성공/실패가 반복될 때의 분포"**

- 동전을 10번 던질 때, 앞면이 나오는 횟수의 분포
- 불량품 검사에서 100개 중 불량이 나오는 개수의 분포

```
예: 동전 10번 던지기 (앞면 확률 = 0.5)
  0번 앞면: 거의 없음
  5번 앞면: 가장 많음
  10번 앞면: 거의 없음
  → 종 모양에 가까움
```

### 왜 중요한가?

- **이진분류** (Phase 1-10 로지스틱 회귀)의 기초
- 성공/실패, 양성/음성, 스팸/정상 → 이항분포

---

## 4. 균등분포 (Uniform Distribution)

모든 값이 **동일한 확률**로 나타남.

```
주사위: 1~6 각각 1/6
난수 생성: np.random.uniform(0, 1)
```

- 실무에서 자주 쓰이진 않지만, 개념적으로 중요
- 랜덤 초기화, 데이터 증강에서 등장

---

## 5. 치우침 (Skewness)

정규분포가 아닌 데이터도 많다.

```
좌로 치우침 (Left Skew):     오른쪽으로 꼬리 ───→ 평균 < 중앙값
  예: 쉬운 시험 점수 (대부분 높음, 일부 낮음)

우로 치우침 (Right Skew):    왼쪽으로 꼬리 ←─── 평균 > 중앙값
  예: 소득 분포 (대부분 낮음, 일부 매우 높음)
```

### 왜 중요한가?

- 치우친 데이터 → **로그 변환(log transform)**으로 정규분포에 가깝게 만들 수 있음
- 1-1에서 배운 "평균 vs 중앙값" 차이가 치우침의 신호

---

## 6. 중심극한정리 (Central Limit Theorem) — 직관만

**"표본의 크기가 충분히 크면, 표본 평균의 분포는 정규분포에 가까워진다"**

원래 데이터가 어떤 분포든 상관없이:
- 충분히 많이 뽑아서 평균을 내면
- 그 평균들의 분포는 정규분포

→ 이게 **정규분포가 그렇게 중요한 이유**

| 여기서 배운 것 | 나중에 만나는 곳 | 어떻게 쓰이는가 |
|--------------|---------------|---------------|
| 정규분포 | 1-5 스케일링 | StandardScaler가 정규분포로 변환 |
| 68-95-99.7 | 1-4 이상치 | Z-score 방법 (3σ 밖 = 이상치) |
| 이항분포 | 1-10 로지스틱 회귀 | 이진분류의 확률적 기초 |
| 치우침 | 1-4 전처리 | 로그 변환으로 분포 보정 |
| 중심극한정리 | Phase 4 통계적 평가 | 실험 결과의 신뢰성 |
