# 2-1. 뉴런과 신경망 구조 — Perceptron, Forward/Backward Propagation

> **Ref: Coursera C2W1 Lab01 "Neurons and Layers" / Stanford CS229 Neural Networks Notes**

---

## 왜 배우는가

Phase 1에서 선형회귀(y=wx+b)와 로지스틱 회귀(sigmoid)를 배웠다.
신경망은 이것을 **여러 겹 쌓은 것**이다.

이 장은 코드 없이 **직관**만 잡는다. 영상을 반드시 보고 오자.

---

## 1. 뉴런 (Neuron) = 선형회귀 + 활성화

```
입력 → [가중치 × 입력 + 편향] → [활성화 함수] → 출력

수식: a = g(wx + b)

w: 가중치 (weight) — Phase 1-7에서 배운 기울기
b: 편향 (bias) — Phase 1-7에서 배운 절편
g: 활성화 함수 — Phase 1-10에서 배운 sigmoid
```

**뉴런 1개 = Dense(1)**

| 활성화 없으면 | 활성화 = sigmoid | 활성화 = softmax |
|-------------|---------------|---------------|
| 선형회귀 (Phase 1-7) | 로지스틱 회귀 (Phase 1-10) | 다중분류 (Phase 1-10) |

→ **Phase 1에서 배운 것이 신경망의 최소 단위**

---

## 2. 층 (Layer) = 뉴런 여러 개

```
Dense(64) = 뉴런 64개가 같은 입력을 받아서 각자 다른 출력

입력(13개) → [64개 뉴런] → 64개 출력
          = (13 × 64) 가중치 + 64 편향
```

---

## 3. 신경망 = 층 여러 개

```
입력층 → 은닉층 1 → 은닉층 2 → 출력층

입력(13) → Dense(64) → Dense(32) → Dense(1)
         [은닉층 1]   [은닉층 2]   [출력층]

코드로:
model = Sequential()
model.add(Dense(64, activation='relu', input_shape=(13,)))
model.add(Dense(32, activation='relu'))
model.add(Dense(1))
```

---

## 4. 순전파 (Forward Propagation)

**"입력에서 출력까지 순서대로 계산"**

```
x → a₁ = g(W₁x + b₁) → a₂ = g(W₂a₁ + b₂) → ŷ = W₃a₂ + b₃

1. 입력 x를 첫 번째 층에 넣는다
2. 가중치를 곱하고 편향을 더한다
3. 활성화 함수를 통과시킨다
4. 다음 층의 입력으로 보낸다
5. 마지막 층의 출력 = 예측값
```

→ 이게 `model.predict(x)`가 하는 일

---

## 5. 손실 계산

순전파로 예측값(ŷ)을 구했으면, 실제값(y)과 비교.

```
Loss = loss_function(y, ŷ)

회귀: MSE (Phase 1-8)
이진분류: BCE (Phase 1-11)
다중분류: CCE (Phase 1-11)
```

→ 이게 `model.compile(loss='mse')`에서 정한 함수

---

## 6. 역전파 (Backpropagation)

**"손실을 줄이기 위해, 오차를 거꾸로 전파해서 가중치를 수정"**

```
1. 순전파로 예측 → 손실 계산
2. 손실에서 시작해서 거꾸로: 각 가중치가 손실에 얼마나 기여했는지 계산 (Chain Rule)
3. 기여도에 비례해서 가중치 수정 (경사하강법, Phase 1-9)
4. 반복 (1 epoch = 전체 데이터 1번 순전파 + 역전파)
```

→ 이게 `model.fit()`이 하는 일
→ 경사하강법(Phase 1-9)을 **자동으로** 해주는 것

---

## 7. 학습 과정 요약

```
model.compile(loss, optimizer)  ← 손실함수 + 최적화 방법 설정
model.fit(X, y, epochs)         ← epochs번 반복:
                                    순전파 → 손실 계산 → 역전파 → 가중치 수정
model.predict(X_new)            ← 학습된 가중치로 새 데이터 예측
```
