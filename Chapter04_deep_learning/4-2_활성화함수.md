# 2-2. 왜 활성화 함수가 필요한가 — ReLU, Sigmoid, Softmax

> **Ref: Coursera C2W2 ReLU Lab / Google MLCC "Activation Functions"**

---

## 왜 배우는가

활성화 함수가 없으면 **레이어를 아무리 쌓아도 선형**이다.
비선형 활성화 함수가 있어야 복잡한 패턴을 학습할 수 있다.

---

## 1. 활성화 함수가 없으면?

```
층1: z₁ = W₁x + b₁
층2: z₂ = W₂z₁ + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)

→ 결국 y = Wx + B (하나의 선형 함수!)
→ 100개 레이어를 쌓아도 1개 레이어와 같다
```

**활성화 함수 = 비선형성을 만드는 것**

---

## 2. ReLU (Rectified Linear Unit)

```
ReLU(x) = max(0, x)

x > 0  → 그대로 통과
x ≤ 0  → 0으로 차단
```

- **은닉층에서 가장 많이 사용**
- 계산이 빠르고, 학습이 잘 됨
- 음수를 차단하는 것이 비선형성을 만든다

### 코드에서
```python
model.add(Dense(64, activation='relu'))
```

---

## 3. Sigmoid

```
σ(x) = 1 / (1 + e^(-x))

출력: 0 ~ 1 (확률)
```

- **이진분류 출력층**에서 사용
- Phase 1-10에서 이미 배움
- 은닉층에서는 안 씀 (학습이 느림)

### 코드에서
```python
model.add(Dense(1, activation='sigmoid'))  # 출력층 (이진분류)
```

---

## 4. Softmax

```
Softmax(z_i) = e^(z_i) / Σe^(z_k)

출력: 각 클래스 확률 (합 = 1)
```

- **다중분류 출력층**에서 사용
- Phase 1-10에서 이미 배움

### 코드에서
```python
model.add(Dense(3, activation='softmax'))  # 출력층 (3클래스)
```

---

## 5. 정리: 어디에 뭘 쓰나?

| 위치 | 활성화 | 이유 |
|------|--------|------|
| **은닉층** | **ReLU** | 비선형성, 빠른 학습 |
| 출력층 (회귀) | 없음 (linear) | 아무 숫자나 출력 |
| 출력층 (이진분류) | sigmoid | 0~1 확률 |
| 출력층 (다중분류) | softmax | 클래스별 확률 |

**외울 것:**
```
은닉층 = ReLU
출력층 = 문제에 따라 (없음 / sigmoid / softmax)
```
