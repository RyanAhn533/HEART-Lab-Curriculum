---

## 왜 배우는가

드디어 **TensorFlow2/Keras로 첫 코드**를 짠다.
이 코드의 구조(**#0→#1→#2→#3→#4**)가 이후 모든 코드의 뼈대가 된다.

**Dense(1) = 2-2 선형회귀와 같은 구조**라는 걸 직접 확인한다.

---

## 핵심: #0→#1→#2→#3→#4 구조

```python
#0. 라이브러리     ← 필요한 것만 import
#1. 데이터         ← 데이터 로드
#2. 전처리 및 분할  ← split, scaler
#3. 모델           ← Sequential → Dense → compile → fit
#4. 평가           ← evaluate, predict, 지표
```

**이후 모든 코드는 이 구조에서 한 섹션만 바뀐다.**

---

## 연결: Chapter 1~2에서 배운 것이 코드에 나오는 곳

```
1-6  StandardScaler     → #2 scaler.fit_transform()
2-2  y = wx + b         → #3 Dense(1) = 같은 구조
2-3  MSE                → #3 loss='mse'
2-4  경사하강법           → #3 optimizer='adam'
2-2  R²                 → #4 r2_score()
```
