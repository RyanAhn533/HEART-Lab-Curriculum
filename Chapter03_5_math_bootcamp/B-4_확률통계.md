## 왜 배우는가

**train data = 표본, 실제 세상 = 모집단. 학습 = 표본으로 모집단을 추정하는 것 = 일반화.**

방향에 주의하라. "모집단이 80% 빨간공이면 표본도 80%쯤"이 아니라,
실전 ML은 반대다 — **우리는 표본(train data)밖에 못 보고, 그걸로 모집단(진짜 세상)을 짐작한다.**
이 방향으로 잡아야 train/test 분할, 과적합, 일반화가 전부 한 줄로 꿰인다:

```
train set에서 잘하는 것  = 표본을 외운 것일 수도 있다
test set에서도 잘하는 것 = 모집단을 짐작하는 데 성공한 것 (일반화)
```

## 문제

### 문제 1 (실험) — 표본이 커지면

평균이 정해진 분포(예: 평균 50, 표준편차 10인 정규분포)에서
표본을 10개 → 100개 → 1000개 뽑아 표본평균을 구하라.
표본이 커질수록 추정이 어떻게 변하는가?

```python
import numpy as np
rng = np.random.default_rng(42)
for n in [10, 100, 1000]:
    print(n, rng.normal(50, 10, n).mean())
```
