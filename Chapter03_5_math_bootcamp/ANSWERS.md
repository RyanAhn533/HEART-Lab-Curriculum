## B-1. 미분과 최소화

**문제 1.** f'(w) = 2(w−2).

| 스텝 | 계산 | w |
|------|------|---|
| 시작 | — | 5 |
| 1 | 5 − 0.1·2(3) = 5 − 0.6 | 4.4 |
| 2 | 4.4 − 0.1·2(2.4) = 4.4 − 0.48 | 3.92 |
| 3 | 3.92 − 0.1·2(1.92) | 3.536 |

→ 최소점 w=2 로 다가간다.

한 발이 골짜기 반대편을 넘어가 버려서, 갈수록 더 멀어진다.
→ 학습률이 크면 손실이 줄기는커녕 폭발한다 (loss = nan 의 흔한 원인).

## B-2. 연쇄법칙 + 계산그래프

**문제 1.** dy/dx = 2(3x+1)·3 = **6(3x+1)**

**문제 2.**
dL/dw = dL/dy · dy/dw = 2(y−t) · x
dL/db = dL/dy · dy/db = 2(y−t) · 1 = 2(y−t)

**문제 3.** x=2, w=3, b=1, t=5:
순전파: wx=6 → y=7 → L=(7−5)²=4
역전파: dL/dy=2(2)=4 → dL/d(wx)=4 → dL/dw=4·x=**8**, dL/db=**4**
검산: 2(y−t)·x = 2·2·2 = 8 ✔

**문제 4.** dL/dw = 2(y−t) · σ(1−σ) · x
(문제 2의 사슬에 σ' 고리 하나가 추가됐을 뿐)

**문제 5.** x=1, w₁=w₂=0.5, b=0, t=1:
z₁=0.5 → a₁=σ(0.5)≈0.6225 → y=0.5·0.6225≈0.3112 → L≈(0.3112−1)²≈0.4744
dL/dy = 2(0.3112−1) ≈ −1.3776
dL/dw₁ = dL/dy · w₂ · σ'(z₁) · x = −1.3776 · 0.5 · 0.6225(1−0.6225) · 1 ≈ **−0.1619**

## B-3. 선형대수

**문제 1.** Wx = [1, 2, 3] (뉴런1: 1·1+0·2=1, 뉴런2: 0+2=2, 뉴런3: 1+2=3)

**문제 2.**
W₂W₁ = [[2, 4], [1, 3]]
z₂ = W₂(W₁x) = (W₂W₁)x — 행렬곱의 결합법칙.
→ 두 층이 결국 행렬 **하나**로 접힌다. 몇 층을 쌓아도 마찬가지.
활성화(비선형)가 이 대수적 접힘을 **막아 주기 때문에**, 그때부터 층을 쌓는 게 의미가 생긴다.

**문제 4.** Dense(64, input 13): 13×64 + 64 = **896**
이어지는 Dense(32): 64×32 + 32 = **2080**

## B-5. 캡스톤

**문제 1.** `B-5_xor.py` PART 1 실행값이 정답:
z₁=[0.5, 0.5], a₁=[0.6225, 0.6225], y=0.6225, L=0.1425
dL/dW₂=[−0.470, −0.470], dL/dW₁ 첫 열=[−0.0887, −0.0887] (x₂=0이라 둘째 열은 0)

**문제 2.**
(a) 선형 모델은 4개 예측이 전부 0.5 근처에서 멈춘다 — 직선 하나로는 (0,1),(1,0)과 (0,0),(1,1)을 못 가른다.
(b) 은닉 2 + sigmoid면 [0, 1, 1, 0] 완벽 분류.
(c) 핵심 문장: 선형변환만으로는 공간을 늘리고·돌리고·밀 수만 있어 경계가 항상 직선이다.
비선형은 공간을 **접을 수 있게** 하고, 접기를 쌓으면 XOR처럼 직선으로 못 가르는 것도 갈라진다.
비선형이 없으면 깊이가 무의미(B-3 붕괴)하므로, 비선형이야말로 '깊은' 러닝의 존재 조건이다.

1. 역전파 = 기울기를 **구하는** 절차(연쇄법칙), 경사하강 = 기울기를 **쓰는** 규칙(θ←θ−η·g) — 이 구분이 있으면 통과
2. "층이 행렬 하나로 붕괴 / 100층 = 1층" 취지면 통과
3. 오답 없음 — 다음 커리큘럼 설계의 입력 데이터
