# B-1. 미분과 '최소화' 감각 — 경사하강법의 뿌리

> **Ref: 3Blue1Brown "Essence of Calculus" 1~3편 / 2-4_경사하강법.md 복습**

---

## 왜 배우는가

학습 = 손실을 최소화 = 함수의 가장 낮은 곳을 찾는 것.
미분(기울기)은 "지금 어느 쪽으로 가야 낮아지는지" 알려주는 나침반이다.

**핵심 한 줄: 기울기의 반대 방향으로 한 발 → 이게 경사하강법의 전부다.**

```
w ← w − η · f'(w)        (η = 학습률)
```

이게 `model.compile(optimizer=...)`가 자동으로 해 주는 일의 뼈대다.

---

## 문제

### 문제 1 (손으로) — 경사하강법을 손으로 체험

```
f(w) = (w − 2)² + 1,  시작점 w = 5,  학습률 η = 0.1
규칙: w ← w − 0.1 · f'(w)
```

경사하강 **3스텝**을 손으로 계산하라. w가 어디로 가까워지는가?

### 문제 2 (실험) — 학습률이 크면?

같은 f에서 **η = 1.1**로 바꿔 3스텝 계산하라.
결과를 보고 "학습률이 크면 왜 문제인지" 한 줄로 정리하라.

### 문제 3 (코드) — 검산

문제 1을 파이썬 5줄로 재현하고 손계산과 일치하는지 확인하라.

```python
w = 5.0
for i in range(3):
    grad = 2 * (w - 2)
    w = w - 0.1 * grad
    print(i + 1, w)
```

### 문제 4 (말로) — 개념 확인

"함수를 최소화한다"는 게 정확히 무슨 뜻인지 **너의 언어로** 설명하라.
(이걸 말로 못 하면 경사하강 전체가 마법으로 남는다)

---

## 주의: MSE 곡면에 대한 흔한 오해

선형 모델에서 MSE는 예쁜 2차 그릇(볼록) 모양이다 — 그래서 위 그림이 통한다.
그러나 **비선형 활성화가 들어간 다층 신경망의 손실 곡면은 2차가 아니라
울퉁불퉁한 비볼록 지형**이다. 2차 그릇은 '가장 단순한 경우의 그림'일 뿐이다.
(나중에 local minima, saddle point를 배울 때 이 각주가 살아난다)
