## 왜 배우는가

데이터 = 벡터. 층 하나 = 행렬곱 한 번. 신경망 순전파 = **(행렬곱 + 활성화)의 반복.**

**핵심 한 줄: 내적 = 뉴런 하나가 하는 일(가중합). 행렬곱 = 뉴런 여러 개를 한꺼번에.**

```
Dense(64), 입력 13개
= (13×64) 가중치 행렬 W 와의 곱 + 편향 64개
= 뉴런 64개가 각자 입력 13개를 내적하는 것
```

(예시의 13은 구 Boston 관례의 특성 수. 실습 4-4의 California는 8특성 — 같은 공식으로 64×8+64=576)

직관 하나: 행렬(선형변환)은 공간을 **늘리고·돌리고·미는** 것만 할 수 있다.
아무리 여러 번 해도 결국 한 번의 늘리고·돌리고·밀기와 같다 — 그래서 경계는 늘 **직선**이다.
비선형(활성화)은 공간을 **접을 수 있게** 해 준다. 접기를 쌓으면 임의로 복잡한 모양이 나온다.

### 문제 1 (손으로) — 뉴런 = 내적

입력 x = [1, 2], 가중치 행렬

```
W = [[1, 0],
```

각 행이 뉴런 하나의 가중치라는 걸 의식하면서 계산할 것.

### 문제 2 (손으로) — ★붕괴 증명 (이 챕터에서 가장 중요한 문제)

```
W₁ = [[1, 2],    W₂ = [[2, 0],
      [0, 1]]          [1, 1]]
```

(1) W₂W₁ 을 계산하라.
(2) 층1: z₁ = W₁x, 층2: z₂ = W₂z₁ 로 두 층을 쌓았을 때,
    z₂ = (W₂W₁)x 임을 확인하라.
(3) 이 결과로 다음 문장을 **네 말로** 설명하라:
    "활성화 함수가 없으면 100층을 쌓아도 1층과 같다. 그래서
     활성화 함수는 '층을 쌓는 것'을 비로소 의미 있게 만든다."

(4-2_활성화함수.md 의 수식 전개가 바로 이 문제다)

### 문제 3 (코드) — 한 층 순전파

numpy로 한 층 순전파 f(Wx + b) 를 구현하라. (f = np.tanh 등 아무 비선형)

```python
import numpy as np
x = np.array([1.0, 2.0])
W = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
b = np.zeros(3)
a = np.tanh(W @ x + b)
print(a)
```

## 외적(outer product) 브리지 — dL/dW는 왜 δ와 x의 외적인가

z = Wx 에서 zᵢ = Σⱼ Wᵢⱼ·xⱼ 이므로 ∂zᵢ/∂Wᵢⱼ = xⱼ.
δᵢ = dL/dzᵢ 라 두면 연쇄법칙으로 **dL/dWᵢⱼ = δᵢ · xⱼ** — 모든 (i,j) 성분을 한 번에 쓰면 `np.outer(δ, x)`.

2×2 예시: δ = [2, 3], x = [1, 4]

```
np.outer(δ, x) = [[2·1, 2·4],   [[2,  8],
                  [3·1, 3·4]] =  [3, 12]]
```

각 성분이 정확히 δᵢ·xⱼ. B-5_xor.py의 `dL_dW1 = np.outer(dL_dz1, x)` 가 바로 이 계산이다.
