## 왜 배우는가

> **표기 대응 (Chapter 4와 헷갈리지 말 것)**
> - 이 부트캠프의 y(예측값) = Chapter 4의 ŷ
> - 이 부트캠프의 t(정답) = Chapter 4의 y
> - z(활성화 전 값)는 4-2와 동일한 표기

**역전파 = 연쇄법칙을 반복 적용하는 것. 그 이상도 이하도 아니다.**

```
dL/dx = (dL/dg) · (dg/dx)     — 영향이 사슬처럼 뒤로 전달된다
```

용어 정리 (헷갈리면 여기로 돌아올 것):

| 용어 | 정체 |
|------|------|
| 손실함수 (MSE) | "얼마나 틀렸나"를 재는 함수 |
| **역전파** | 손실을 각 가중치로 미분한 값(기울기)을 **연쇄법칙으로 계산하는 절차** |
| **경사하강법** | 그 기울기로 가중치를 **얼마나·어느 방향으로 바꿀지** 정하는 규칙 |

역전파는 기울기를 '구하는' 방법이고, 경사하강은 기울기를 '쓰는' 방법이다. 분리해서 기억하라.

---

## 계산그래프 — 은유와 계산을 잇는 다리

수식을 **그래프**로 그리면 순전파/역전파가 눈에 보인다.

```
L = (y − t)²,  y = wx + b 를 그래프로:

  w ──┐
      [×]── wx ──┐
  x ──┘          [+]── y ──[(y−t)²]── L
  b ─────────────┘

순전파(→): 왼쪽에서 오른쪽으로 값이 흐른다
역전파(←): 오른쪽에서 왼쪽으로 기울기가 흐른다
           각 노드는 "받은 기울기 × 자기 국소 미분"을 뒤로 넘긴다
```

이 그림에서 `dL/dw`는: L에서 출발 → `dL/dy = 2(y−t)` → `dy/d(wx) = 1` → `d(wx)/dw = x`
→ 곱하면 `dL/dw = 2(y−t)·x`. **이게 역전파의 전부다.**

## 문제

### 문제 1 (손으로) — 워밍업

y = (3x + 1)² 의 dy/dx 를 연쇄법칙으로 구하라.

### 문제 2 (손으로) — 선형회귀 역전파의 실체

L = (y − t)², y = wx + b 일 때 **dL/dw 와 dL/db** 를 연쇄법칙으로 구하라.
(이게 2-2 선형회귀가 학습하는 원리 그 자체다)

### 문제 3 (그리기) — 계산그래프 ★핵심

문제 2의 식을 **계산그래프로 직접 그려라.**
- 순전파 방향으로 x=2, w=3, b=1, t=5 를 넣어 각 노드의 값을 적는다
- 역전파 방향으로 각 엣지에 기울기를 적는다 (L부터 거꾸로)
- 마지막에 dL/dw 숫자가 문제 2의 식과 일치하는지 확인

### 문제 4 (손으로) — 한 뉴런의 역전파 (backprop 최소 단위)

y = σ(wx + b), L = (y − t)² 일 때 dL/dw 를 구하라. (힌트: σ' = σ(1−σ))
→ 문제 2와 비교해 보라. **비선형 σ가 끼면서 사슬에 고리가 하나 늘었을 뿐이다.**

### 문제 5 (손으로) — 2층으로 확장

입력 → 은닉뉴런 1개(σ) → 출력 의 작은 망에
x=1, 모든 가중치=0.5, b=0, t=1 을 넣고 순전파 값과 dL/dw₁ (첫 층 가중치의 기울기)을 구하라.
→ 사슬이 한 층 더 길어졌을 뿐, 규칙은 같다.
