## 미니 개념 카드 (영상 안 봤어도 여기부터 시작 가능)

**언롤(unroll)** — 같은 셀 하나가 시간을 따라 반복 적용되는 것을 펼쳐 그린 것:

```
x₁ → [셀] → h₁ → [셀] → h₂ → [셀] → h₃ → ...
      ↑같은 W     ↑같은 W     ↑같은 W
```

**h vs C** — RNN엔 h(은닉 상태)만 있다. LSTM은 여기에 **C(셀 상태)**를 하나 더 둔다:
h = 매 시점 밖으로 내보내는 '작업 기억', C = 게이트로만 건드리는 '장기 기억 컨베이어벨트'.

**LSTM 게이트 4개** (각 한 줄):

| 게이트 | 역할 |
|--------|------|
| f (forget) | 옛 기억 C를 얼마나 유지할지 (0~1 밸브) |
| i (input) | 새 정보를 얼마나 받아들일지 (0~1 밸브) |
| C̃ (candidate) | 받아들일 새 정보의 '내용' (tanh, −1~1) |
| o (output) | C에서 얼마를 꺼내 h로 내보낼지 (0~1 밸브) |

## RNN 한 줄 정의

```
hₜ = tanh(Wₓ·xₜ + Wₕ·hₜ₋₁ + b)

같은 Wₓ, Wₕ 를 매 시점 재사용한다. (CNN이 공간에서 필터를 재사용하듯, RNN은 시간에서)
```

## 문제

### 문제 1 (손으로) — RNN 3스텝 언롤

스칼라 RNN (tanh 생략, 선형 버전으로 감각만):

```
hₜ = wₓ·xₜ + wₕ·hₜ₋₁,   wₓ = 1, wₕ = 0.5, h₀ = 0
입력 시퀀스: x = [1, 0, 0]
```

(1) h₁, h₂, h₃ 를 손으로 계산하라.
(2) h₃ 안에 x₁의 흔적이 얼마나 남아 있는가? (0.5가 몇 번 곱해졌나)

### 문제 2 (손으로) — ★기울기 소실을 숫자로

문제 1에서 dh₃/dh₁ = wₕ² 이다 (wₕ가 시점마다 곱해지므로).

(1) wₕ = 0.5 일 때, h₁에서 h₁₀까지 9스텝을 거치므로 기울기에 wₕ⁹ 이 곱해진다. 값은?
(2) wₕ = 1.5 라면? 이건 무슨 문제인가?
(3) 결론을 한 줄로: "RNN이 긴 시퀀스에서 앞쪽 정보를 못 배우는 이유는 ___"
(B-2에서 σ'=σ(1−σ)≤0.25 가 사슬마다 곱해지던 것과 같은 현상이다)

### 문제 3 (말로) — LSTM 게이트: 소실의 해법

LSTM의 셀 상태 업데이트: `Cₜ = fₜ·Cₜ₋₁ + iₜ·C̃ₜ` (f=forget, i=input 게이트)

(1) forget 게이트 fₜ가 **전부 1**이면 Cₜ₋₁에 무슨 일이? — 문제 2의 wₕ와 비교하면 왜 이게 소실의 해법인가?
(2) fₜ가 **전부 0**이면? (DIAGNOSTIC_TEST 문제 15와 같은 질문)
(3) 게이트 값이 0~1인 이유는? (어떤 활성화가 만들어 내나)

### 문제 4 (손으로) — LSTM 게이트 1스텝

스칼라 LSTM, 모든 가중치 = 0.5, 편향 = 0, C₀ = 1, h₀ = 0, x₁ = 1:

```
f₁ = σ(0.5·x₁ + 0.5·h₀) = σ(0.5) ≈ 0.62
i₁ = σ(0.5) ≈ 0.62
C̃₁ = tanh(0.5) ≈ 0.46
```

(1) C₁ = f₁·C₀ + i₁·C̃₁ 을 계산하라.
(2) o₁ = σ(0.5) 로 두고 h₁ = o₁·tanh(C₁) 을 계산하라.
(3) "옛 기억(C₀)의 62%를 유지하고, 새 정보의 62%를 받아들였다" — 이 문장을 위 숫자로 확인하라.

### 문제 5 (손으로) — 파라미터 수

`LSTM(64)`, 입력 특성 8개일 때 파라미터 수는?
힌트: 게이트 4개(f, i, o, C̃) 각각이 `(입력 8 + 은닉 64) × 64 + 64` 를 가진다.
→ `model.summary()` 로 검산하라.

### 문제 6 (코드) — 소실을 눈으로

```python
import numpy as np
for w in [0.5, 0.9, 1.0, 1.1, 1.5]:
    print(w, "→ 20스텝 후 기울기 배율:", round(w**20, 6))
```

w<1 이면 소멸, w>1 이면 폭발, 1 근처만 생존 — LSTM의 f≈1 이 바로 이 '1 근처 고속도로'다.
