## CNN

**문제 1.**
(1) (5−3+0)/1+1 = **3×3**
(2) 출력:

```
0 3 3
0 3 3
0 3 3
```

(계산 예: 중앙 위치의 윈도우는 입력 2~4열 — 각 열합이 [3, 3, 0]이고 필터 열가중치가 [+1, 0, −1]이므로 3·1 + 3·0 + 0·(−1) = 3 − 0 = 3)
(3) 값 3이 나오는 곳 = 입력에서 1→0으로 꺾이는 **수직 경계**. 필터 = 수직 에지 검출기.

**문제 2.**
Conv(5, pad2, s1): (32−5+4)/1+1 = **32** → MaxPool: **16**
Conv(3, pad0, s1): (16−3)/1+1 = **14** → MaxPool: **7**

**문제 3.**
(1) 784×128 + 128 = **100,480**
(2) 3×3×1×32 + 32 = **320**
(3) 314배 차이. CNN은 필터를 이미지 전체에 **재사용**(가중치 공유)하고,
픽셀은 **가까운 픽셀끼리만** 의미가 있으므로(지역성) 작은 필터로 충분하다.

**문제 4.**

```
4 5
7 8
```

버리는 것: 특징의 정확한 위치. 지키는 것: 특징의 존재 여부. → 약간의 이동에 강해진다.

## RNN / LSTM

**문제 1.**
h₁ = 1, h₂ = 0.5, h₃ = **0.25**. x₁의 흔적 = 0.5² (매 시점 0.5가 곱해짐).

**문제 2.**
(1) 0.5⁹ ≈ **0.00195** — 사실상 0. 앞쪽 시점의 기울기가 도착하지 않는다.
(2) 1.5⁹ ≈ 38.4 — **기울기 폭발** (loss가 nan으로 튀는 흔한 원인).
(3) "같은 wₕ(<1)가 시점 수만큼 반복해서 곱해지기 때문" — 기울기 소실.

**문제 3.**
(1) f=1 이면 Cₜ = Cₜ₋₁ + (새 정보): 옛 기억이 **곱셈 감쇠 없이** 그대로 흐른다.
문제 2의 wₕ 반복곱 자리에 '1'이 곱해지는 셈 — 기울기가 소멸하지 않는 고속도로.
(2) f=0 이면 과거를 전부 잊는다. 매 시점 리셋 — 사실상 기억 없는 망.
(3) sigmoid. 0~1 사이라서 "얼마나 통과시킬지"의 비율(밸브)로 쓸 수 있다.

**문제 4.**

(3) C₁ ≈ 0.62(옛 기억 유지분) + 0.29(새 정보 수용분) — 문장 그대로.
